# StudyOS V2

A polished, private/friends-only Grade 10 CBSE study hub built with **plain HTML, CSS and JavaScript**.

## Included

- Private access gate
- Grade 10 CBSE Mathematics, Science, Social Science and English library
- Chapter cards with quick revision points
- Search across chapter names, descriptions, tags and points
- Saved/bookmarked chapters
- Revision progress stored in `localStorage`
- Needs-revision / revised / important filters
- Chapter detail modal
- Previous/next navigation
- Keyboard shortcuts: `Ctrl + K`, `Esc`, `←`, `→`
- Light/dark theme
- Responsive phone/tablet/desktop layout
- Surprise-me random revision
- No frameworks, build tools or external dependencies

## Run

Just open `index.html` in a browser.

## Access code

```text
STUDY10
```

This is only a client-side gate. Anyone who can inspect the source can see the code, so it is **not real security**.

## Files

- `index.html` — structure and UI
- `style.css` — responsive design and theme
- `app.js` — chapter data, search, filters, progress and interactions

## Notes

The content is designed as a revision hub rather than a replacement for the NCERT textbook or official CBSE syllabus. Verify exact school/year portions before relying on it for an exam.
